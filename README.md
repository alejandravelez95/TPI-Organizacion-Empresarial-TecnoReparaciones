## Descripción del sistema 
TECNO REPARACIONES es una empresa dedicada a la recepción, diagnóstico y reparación de equipos informáticos. Con el objetivo de optimizar la gestión de clientes, equipos, órdenes de trabajo, diagnósticos, presupuestos, repuestos y cobros, se propone el desarrollo del Sistema de Gestión de Servicios Técnicos (SGST).

El proyecto aborda el análisis organizacional, la definición de procesos de negocio, el diseño de datos y la planificación del ciclo de vida del software, con el fin de implementar una solución centralizada que garantice la trazabilidad completa de las reparaciones, el control de stock y la mejora continua de la operación de la empresa.

## Flujo de trabajo
- `main`: versión estable de la documentación.
- `develop`: integración de las ramas de trabajo antes de producción.
- `feature/*`: ramas por unidad de trabajo (bpmn, historias-usuario, control-indicadores).
- Todo merge a `main` se realiza mediante Pull Request con revisión.
